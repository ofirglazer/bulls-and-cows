Bulls and Cows Game Solver

How to Use:

Classic Mastermind game. The AI solver tries to crack the secret code.

  • Human Opponent: the solver gives the next guess, you reply with the feedback
  • Bot Opponent: the solver gives the next guess, the bot gives the feedback

The opponent (other human or the bot) will generate a secret code using colors. The solver AI will try to guess the code, and you'll see how it narrows down the possibilities with each guess.

  • Bulls (🎯): Correct color in the correct position
  • Cows (⚪): Correct color but wrong position
